# Android-виджет «Планы на двоих»
Нативный виджет для Android 8+ с ручным изменением размера (от 1×2 до 4×4, порядок: высота × ширина).
Настройки: сплошной фон/градиент, произвольные HEX-цвета, угол градиента, случайные цвета и угол, прозрачность, цвет текста и иконок.
Данные только через защищённую привязку устройства к @PlansForTwoBot. Запрос обновления планируется ОС раз в сутки; Android может задерживать фоновые события. Ручной запрос в приложении не считается автоматическим.
Нажатия на даты открывают только установленный Telegram через tg://resolve, без перехода на сайт.
Приложение получает данные только о своей паре. Токен бота и ключи Supabase в APK не встраиваются.
Сборка тестового APK в GitHub Actions: Android Widget APK; временная debug-подпись GitHub Actions не гарантирует обновление без удаления при будущей пересборке.
